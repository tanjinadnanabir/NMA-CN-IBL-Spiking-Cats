# 📖 About

**Spiking Cats** is a research project developed as part of the **Neuromatch Academy (NMA) Computational Neuroscience** program using the **International Brain Laboratory (IBL)** dataset.

Our goal is to understand how neurons communicate, represent information, and drive behaviour by analysing neural spike trains recorded from thousands of neurons across multiple brain regions.

This project combines ideas from:

- 🧠 Computational Neuroscience
- 📊 Neural Data Analysis
- ⚡ Spike Train Analysis
- 🤖 Machine Learning
- 📈 Statistical Modelling
- 🐭 Decision Making
- 🔬 Brain-wide Neural Recordings

- Understand decision-making processes

- Visualize neural activity
- Generate reproducible scientific analyses

# 🧬 Research Questions

Some of the questions explored include:

- How do neurons encode sensory information?
- Which brain regions contribute most to decision making?
- How do spike trains change during different behavioural states?
- Can neural activity predict behaviour?
- How does population coding emerge?
- What latent neural representations exist?
- How stable are neuronal firing patterns?
- Can machine learning decode behavioural variables?

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Spiking-Cats.git
```

Enter the project

```bash
cd Spiking-Cats
```

Install dependencies

```bash
pip install -r requirements.txt
```

Launch Jupyter

```bash
jupyter notebook
```

---

# ▶️ Usage

Run notebooks inside the `notebooks/` directory or execute Python scripts from the `src/` folder.
